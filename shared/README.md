# 公共运行模块

`shared/` 提供跨实验复用的任务调度、材料版本管理和数据存档功能。各研究任务的变量与条件由对应实验目录定义；用户级执行规则集中于[运行指南](../docs/运行指南.md)。

## 模块职责

| 文件 | 功能 |
|---|---|
| `cli.py` | 命令行、批次计划读取、预览及串行/并行执行 |
| `tasks.py` | 任务类型与各实验构造器的分发 |
| `common.py` | 路径、模板、配置、密钥及摘要等公共工具 |
| `api.py` | 独立 API 请求与请求参数组装 |
| `materials.py` | 实验材料快照、文件清单和摘要核对 |
| `batch.py` | 批次输入、参数及试次计划的一致性核对 |
| `storage.py` | 原始输入输出记录、状态和失败重试 |
| `validation.py` | 解析结果、检查字段范围及必要内容 |
| `exports.py` | 批次 CSV 与任务汇总表导出 |
| `migration.py` | 历史结果迁移和原始档案保留 |

## 实施约束

- **请求结构**：每试次发送一条独立 `user` 消息；模型配置来自任务对应的 `settings.json`。
- **批次一致性**：输入内容、模型参数及试次计划固定；仅作为追溯信息的源码摘要与并发设置不全部参与当前续跑比较。
- **记录原则**：原始响应及失败尝试保留；CSV可重新导出，不取代原始数据。
- **材料版本**：实验2、3读取各自独立的固定材料快照。
- **存储结构**：字段含义、异常状态和分析注意事项见[数据与存档](../docs/数据与存档.md)。
