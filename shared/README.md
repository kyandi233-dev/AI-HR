# 公共运行工具

- **cli.py：** 读取运行计划、预览任务、调度串行或并发请求。
- **tasks.py：** 任务名称与实验脚本的对应表。
- **common.py：** 文件读取、模板填充、密钥读取、时间和摘要。
- **materials.py：** 将选定材料复制成实验版本，核对材料文件摘要。
- **api.py：** 使用单条user消息发送请求。
- **storage.py：** 保存输入、原始回答、校验状态及重试记录。
- **batch.py：** 按任务输入、模型参数和试次计划检查批次一致性。
- **validation.py：** 检查必需字段、数值范围、权重和与非空理由。
- **exports.py：** 导出按计划顺序排列的批次CSV和任务总表。
- **migration.py：** 转换旧格式数据，归档原文件。

## 运行设置

- **模型参数来源：** 各阶段config/settings.json。
- **当前温度：** 所有任务temperature=1，thinking=disabled。
- **输出上限：** 生成3000，原则与招聘评价2200，材料审核与评价1600。
- **并发数：** 默认1；`--concurrency 4`设置为4。
- **密钥优先级：** 当前终端环境变量 → 项目根目录.env。
- **源码摘要：** 记录每次尝试使用的代码版本，供追溯。
- **数量：** 由计划和可选的--limit确定。
- **执行：** --execute采集；--retry-failed重试已有失败或中断项。
