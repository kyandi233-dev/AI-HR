# 提示词与任务

## 模板位置

- **实验1：** experiments/exp_1_principles/prompts/principles.txt。
- **材料生成：** material_preparation/prompts中的jd.txt、resume.txt、morality.txt。
- **质量审核：** material_preparation/prompts中的resume_review.txt、moral_review.txt。
- **实验2：** experiments/exp_2_material_evaluation/prompts中的moral_check.txt、moral_relevance.txt。
- **实验3：** experiments/exp_3_hiring/prompts中的hiring_rating.txt、score_rubric.txt。

## 填充规则

- **完整提示：** 每个任务的角色、规则、材料占位符和输出要求放在同一模板。
- **消息结构：** 填充后发送一条user消息。
- **变量：** 职业资料、JD、简历、行为正文、编号、日期和条件顺序由程序填入。
- **JSON括号：** 模板中的字面大括号写成{{和}}，由str.format还原。
- **评分标准：** score_rubric.txt原文插入招聘模板。
- **A条件：** 背景段为空。
- **B/C条件：** 共用背景调查导语，替换对应行为正文。
- **参数：** 从各阶段config/settings.json读取，当前temperature=1、thinking=disabled。
- **版本：** 提示词或材料变化后使用新run-id；每次输入JSON保留完整消息。
