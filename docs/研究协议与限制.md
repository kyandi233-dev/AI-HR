# 研究协议与限制（执行前必须阅读）

## 1. 当前研究问题与实验单位

研究对象是 DeepSeek 具体版本的 API 模型。首批材料从 O*NET 建立职业资料，生成一个 JD 对应多份普通合格水平简历。招聘结果比较：A=JD+简历，B=同一 JD+简历+中性私人背景，C=同一 JD+简历+负面私人道德背景。

主要比较 C-B；辅助比较 B-A、C-A。绝不能将重复调用次数代替独立职业、简历、故事的数量。统计分析至少保留 `occupation`、`resume_id`、`pair_id` 和 `repeat` 标识。是否使用多层模型以及随机效应结构需根据实际数据与推断目标决定。

## 2. 抽象原则与招聘判断严格分离

抽象原则调查不提供任何 JD、职业、具体候选人或道德故事。四种顺序 M12、M21、A12、A21 分别以独立 API 请求运行，记录介绍顺序、任务顺序、重复次数。不能因为顺序效应统计不显著就声称已证明“没有顺序效应”；应查看效应大小及置信区间。

原则调查的权重是模型自陈的规范性偏好，不是实际招聘评分中的已验证因果权重；跨一般原则与具体职业的差异还包含情境差异。

## 3. 生成、审核、招聘评价不可混用

- 生成模型可以收到内部资料规则；生成数据不作为实验判断结果。
- 文字质量审核模型只检查材料，不进入正式招聘评价。
- 正式招聘模型只看到普通招聘任务，不看到“实验”“研究”“已知偏差”“控制条件”等研究目的。
- 同一 A/B/C 批次的模型 ID、thinking、temperature、评分标准、JD、简历版本一致。B 与 C 的相同配对只替换行为摘要正文。
- 每条测量以全新会话发送，仅包含一条 user 消息；角色、规则和材料合并在同一份完整提示词中。不要在模型上下文中展示上一条任务或以前评分。

- 提示词模板跨职业复用，具体材料按设计替换；开发与预实验阶段可修订并记录版本，正式实验同批次固定模板、评分锚点和参数。消息角色结构变化后须使用新的 run-id，不能直接与旧结构下的输出视为同一配置。

## 4. 材料来源与冻结

- 职业材料的外部来源限 O*NET。必须保留访问时间、职业代码、资料原文及人工筛选记录。细分职位/公司设定可由研究者提出，但不能伪称为 O*NET 原文。
- 旧版软件工程师 JD/简历没有导入，属于历史草案；新的完整链条需重新生成与审核。
- 招聘初筛材料中控制人口信息、学校/雇主声望、人际道德显性标签。
- 道德材料统一采用第三人称背景调查摘要，自然叙述私人行为；不逐条标记来源或“已核实”。
- `drafts` 不能用于 A/B/C，只有研究者确认后进入 `approved`。材料修改后应启用新批次 ID。
- 若同一批次先用模型结果挑选材料，再在同样材料上报告评分，应将筛选数据与正式评价数据严格分离；报告材料筛选过程及剔除标准。

## 5. 预检验指标的解释

道德效价（1–7）、基础归属、可理解性、自然性属于对同一故事的属性评定。岗位的直接专业关联依赖具体 JD，故独立为 `moral-relevance --occupation`；不能用某职业的“低关联”结论自动推广到其他职业。不同背景的负面情绪强度、信息诊断性或可信度仍可能是潜在混淆；当前 C-B 估计的是负面道德相对中性行为的总体附加影响，不能单凭此差异分离“道德性本身”。

## 6. 评分与报告

评分锚点为研究者根据 Kim et al. 的方法设计的初稿，还需检验跨职业理解的一致性。模型输出中的 `reason` 是开放式自陈理由，不是关于内部推理机制的因果证据，也不主动问“有没有用私人信息”。

- JSON 空响应、截断、拒答、网络失败全部保留异常记录，不纳入有效评分。
- 当前程序不会自动重新抽样失败评价；只有明确手动 `--retry-failed`，并保留失败的历史记录。
- `temperature=0` 不保证确定性；模型名和参数一致也不一定意味着后端版本完全不变。保存 `system_fingerprint`（如果返回）、精确时间、模型实际名称、原始响应和用量。
- 每次调用应事先确定最大预算、批次规模与停止规则。跨日期或模型更新应标记批次差异。
- Python 内部任务顺序伪随机种子由 run-id 导出：保证批次可重排复现，不保证模型输出可重现。

## 7. 数据伦理与隐私

仅使用合成候选人和虚构背景行为；不要上传真人履历、个人手机号、地址或从社交媒体抓取的真人资料。API Key 只放环境变量，不保存到日志。实验报告应如实注明模型版本、参数、Prompt、O*NET 来源、合成材料、拒答比例、局限及任何人工选择和排除步骤。

## 8. 局限与后续研究

四职业暂为历史候选池（客户服务岗位高度依赖社会性技能，是否适合作为“专业技术”任务需进一步判断）；可暂时只选一个职业走通流程，但不能把单职业结果当成跨职业结论。各职业 JD 的难度、教育要求和基线评分仍可能影响跨职业效应的可比性。

本程序主要负责可靠调用、校验与保存，**不自动执行推断性统计分析**，也不提供“当前研究已验证”的保证。
