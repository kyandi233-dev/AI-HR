# 研究设计

## 1. 研究对象与问题

- **研究对象**：DeepSeek API 模型在受控招聘评价任务中的输出行为。
- **核心问题**：专业简历证据保持一致时，岗位外私人道德信息是否改变专业能力评价和招聘推荐？
- **扩展问题**：影响是否因道德内容、职业或模型版本而变化；模型自陈的招聘原则与具体评分是否一致。
- **适用范围**：结果描述被测模型、材料、职业及运行条件下的评价变化，不推断模型内部决策机制或真实候选人的工作绩效。

本研究将**专业能力判断**定义为：模型根据岗位相关教育、工作经历、专业技能和工作成果，对候选人完成目标岗位专业任务能力的评价。**招聘推荐**以总体岗位适任性及面试推荐概率表示；它们与专业能力判断分别报告。

当前代码使用第三人称**补充信息摘录（来源于公开社交媒体动态或熟人访谈片段）**呈现候选人在工作之外的日常私人行为。若后续更改信息来源或呈现格式，应同步更新材料、提示词和研究协议。

## 2. 研究组成

| 环节 | 研究任务 | 设计要点 |
|---|---|---|
| 实验1：抽象原则 | 询问模型在一般招聘初筛中如何权衡专业能力与私人道德信息 | 操纵两类定义的顺序与两项判断任务的顺序，形成4种条件 |
| 材料准备 | 基于 O*NET 和岗位描述生成匿名专业简历、配对私人行为摘要 | 生成普通合格水平的简历；审核自然性、职业合理性与故事内容 |
| 实验2：材料评价 | 独立评价故事性质及其直接专业关联性 | 对中性与负面故事分别测量；不承担简历能力评价 |
| 实验3：招聘评价 | 比较相同专业材料在三种信息条件下的评价 | A/B/C 采用独立模型调用，主要检验 C－B |

### 实验1：原则判断

- **任务1**：专业能力判断规则。
- **任务2**：面试推荐判断规则。
- **顺序条件**：`M12`、`M21`、`A12`、`A21`；首字母表示道德或能力定义先呈现，数字表示任务顺序。
- **测量**：信息优先类别、能力与道德权重（各0–100，合计100）、两类信息的重要性（1–7）以及自陈理由。
- **解释**：测量模型的显性规则陈述；不能将自陈权重当作实际招聘评分中的隐含权重。单次调用同时回答两个任务，分析时保留其共同调用来源。

### 实验3：招聘评价

| 条件 | 模型收到的信息 |
|---|---|
| A | 同一岗位描述及专业简历 |
| B | A 条件材料＋中性私人行为背景 |
| C | A 条件材料＋负面私人道德行为背景 |

- **主要比较**：`C－B`，估计负面道德背景相对中性私人背景的评价差异。
- **辅助比较**：`B－A`、`C－A`，考察加入私人信息后的变化。
- **配对结构**：每份简历在 A 条件下独立评价；对于每个故事配对，B/C 使用同一岗位、同一简历以及相同的背景调查导语。
- **重复调用**：相同输入可多次独立调用；重复次数由批次计划控制，条件顺序由程序随机化。
- **解释限制**：当前 C－B 包括负面道德事件相对于中性事件的整体差异，可能同时涉及负性、严重程度、可信度等属性；不应直接解释为纯粹的“道德性因果效应”。

## 3. 材料构造与筛选

### 职业及专业材料

- **岗位资料**：完整保留 O*NET 结构化存档，JD生成按固定配置读取九个约定模块，不对模块内条目取前N项；其中Essential Skills、Transferable Skills为少量认知能力要求提供补充来源。本轮四个职业统一要求3年以上相关工作经验，不额外设定公司背景、细分岗位或岗位层级。学历按 Education 占比最高层次转换为“相应学历及以上”，记录转换依据；社会性技能排除规则以确认的 JD 提示词为准。原始输出保留依据记录，人工审核后由固定脚本提取岗位公告，详见[JD与简历生成](JD与简历生成.md)。
- **简历**：仅包含教育背景、相关经历、专业技能和工作成果。当前候选生成目标为中等、低两种水平，每职业每水平两份；通过固定的教育相关性、经验年限、任务范围、技能应用和成果范围控制，不在正文自报水平，不赋予预设能力分数。中等目标接近基本要求，低目标仅部分匹配，实际水平待独立基线预评估核查；是否将能力水平纳入正式实验因素尚需另行确定。
- **简历质量审核**：当前检查文本自然性、专业合理性和时间线一致性；此环节不产生独立的能力评分。

### 私人行为材料

- **生成形式**：每个 `pair_id` 包含一个中性行为摘要和一个负面道德行为摘要，标记预设道德基础。
- **配对要求**：两条摘要在情境、长度、叙述角度和信息量上尽量接近；不直接描述岗位技术能力或工作绩效。
- **实验2现有指标**：道德效价、道德基础归属、可理解性、自然性、与目标岗位的直接专业关联性。
- **尚待完善**：严重程度与可信程度的专门测量、材料纳入阈值及拒答的独立识别规则。
- **评价来源**：材料准备的 `moral-review` 与实验2的 `moral-check` 目前使用相同的测量提示词；用途与存档分开，不宜视为两种独立测量方法。

### A 条件与简历能力预评估

- **现有功能**：`baseline` 调用与招聘实验相同的评分规则，只运行 A 条件，可为候选简历提供模型评价。
- **预实验用途**：可根据专业能力四项指标的水平与稳定性选择符合研究范围的简历；目前尚未确定筛选阈值及自动筛选程序。
- **正式实验**：应对选定简历重新独立采集 A/B/C；筛选阶段的 A 结果不并入正式 A 数据。
- **材料版本**：筛选后建立新版本并保留材料纳入和排除记录。当前快照脚本默认纳入来源目录下全部 `R*.txt`，尚无按简历编号自动筛选功能。

## 4. 测量与数据分析

| 测量对象 | 指标 | 范围 |
|---|---|---|
| 专业能力判断 | 教育与岗位匹配、相关工作经历、专业技能、项目或代表性成果 | 每项1–5 |
| 招聘推荐 | 总体岗位适任性 | 1–5 |
| 招聘推荐 | 面试推荐概率 | 0–100% |
| 私人行为属性 | 道德效价、可理解性、自然性、岗位直接关联性 | 每项1–7 |
| 抽象原则 | 信息优先类别、权重、重要性和理由 | 类别、0–100、1–7、文本 |

- **主要分析**：针对专业能力四项指标及招聘推荐指标报告 C－B 的方向、大小及不确定性；B－A、C－A 作为补充比较。
- **分层与配对**：保留职业、`resume_id`、`pair_id`、重复调用和批次标识。B/C 在相同简历与故事配对内比较。
- **共享基线**：同一简历的 A 结果服务于多个故事配对，不可因数据展开而计为多个独立的 A 观测。
- **多维扩展**：比较不同道德基础与职业的效应时，考虑故事材料本身的变异及样本量限制。
- **理由编码**：评分理由可按专业简历证据、私人行为信息及额外推断等类别记录；理由是显性解释，不等同于模型内部机制。
- **实施前待定**：专业能力复合分数的计算规则、正式实验重复次数、材料筛选标准及主要统计模型。

## 5. 解释范围与限制

- 虚构简历和背景摘要不等价于真实招聘决策；模型评分不能验证候选人的客观能力。
- 当前研究对象限于实际调用的模型版本、日期、职业和材料样本；跨模型与跨职业结论须以新增数据检验。
- 负面道德材料与中性材料的差异可能包含严重程度、负性或可信度；有关指标需要进一步控制。
- 模型自陈原则、评分理由和实际数值评分属于不同证据类型，应分别报告。
- 材料筛选、实验评分与正式数据分析须留有独立标识，避免将预实验结果直接用于正式效应估计。

具体提示词、实验任务与当前实现状态见各模块 README；操作配置见[运行指南](运行指南.md)。
