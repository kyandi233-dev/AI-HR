# 道德材料编制速览

更新：2026-11-24。本文回答三个问题：六类主题分别指什么，如何写成行为材料，以及每一步参考什么信息。具体候选见[私人行为情境大纲](私人行为情境大纲.md)；理论展开见[道德概念与六类材料编制依据](道德概念与六类材料编制依据.md)。

## 1. 理论、定义与操作化

本研究采用道德基础理论（Moral Foundations Theory，MFT）组织私人行为的内容，采用道德基础情境材料（Moral Foundations Vignettes，MFV）作为主要编写参照。六类是材料抽样主题；本研究不据此认定大语言模型具有人类的道德心理机制。

**操作化的共同单位**：候选人在工作之外实施的一件具体行为，写成第三人称背景调查摘要；每件事件分别编写负面版和中性版。操纵行为信息，测量模型如何评价，不直接用“人品差”等特质标签替代行为。

| 主题 | 理论上的核心关切 | 本研究如何写成行为 | 优先避免的混淆 |
|---|---|---|---|
| 关怀／伤害 | 他人的痛苦、脆弱与照料需要 | 描述具体的情感伤害或对动物的伤害；优先选择无等级关系的私人事件 | 上下级关系、群体背叛；仅仅表达不喜欢某人 |
| 公平／欺骗 | 合作、互惠和不公获利 | 描述私人游戏、排队或共同付费中，通过作弊、插队或搭便车获利的行为 | 职场造假、技术任务；将所有撒谎都归为公平 |
| 忠诚／背叛 | 群体成员义务、团结和内外群体关系 | 交代成员身份与竞争对手，描写公开贬损本群体或在竞争中公开倒向对手的行为 | 普通朋友失约；将客观批评或欣赏对手直接认定为不道德 |
| 权威／颠覆 | 对正当权威、等级与传统的尊重 | 在家庭或私人兴趣活动中，描写对被承认的长辈、教师或教练的公开不尊重 | 反抗不正当控制；一般场合礼仪；工作中的服从性 |
| 神圣／堕落 | 身体或精神污染、贬损与纯洁关切 | 本轮先尝试与身体厌恶有关的私人事件，单独检查是否被理解为道德问题 | 单纯不卫生、健康风险、性身份、疾病标签；其他人的权益受损 |
| 自由／压迫 | 支配、胁迫及个人选择受到限制 | 明确候选人施加控制，迫使另一人改变原本可自主决定的生活选择 | 普通建议、双方协商；照顾未成年人的必要限制 |

定义主要依据 Graham 等（2013）；行为编写范围主要依据 Clifford 等（2015）；自由主题另参考 Iyer 等（2012）。本研究的公平材料聚焦作弊与搭便车，不声称覆盖所有公平观念。

## 3. 所有情境共用的编写标准

- **固定比较**：A＝岗位描述＋简历；B＝再加中性私人事件；C＝再加负面私人事件。主要比较 C－B，沿用当前[研究设计](../../研究设计.md)。
- **一对一个事件**：固定人物关系、场景、事件起因和叙述视角，主要改变候选人的行为；两版均包含具体活动，篇幅和细节尽量接近。
- **中性版本保持普通**：采用日常行为，不改成主动帮助、牺牲、维护权益等明显正面行为，也不只写“没有不良记录”。若场景已经产生明显救助义务，应重选场景。
- **保留必要事实**：负面版必须看得出是谁做了什么；可写明必要的意图或规则，不额外添加恶意动机、旁人谴责、处分结果或能力结论。
- **排除直接专业证据**：不写工作表现、职业违法、技术操作或项目成果。逐个岗位检查；不能仅因发生在私人生活就判定与专业能力无关。
- **来源与效度分别记录**：记录原条目、改编内容和新中性版。原条目的人类评价不转移给改编版本，不按招聘评分是否下降来筛选材料。

## 4. 写完以后检查什么

| 属性 | 希望确认的结果 | 当前状态 |
|---|---|---|
| 道德效价 | 负面版明确低于中性版；中性版接近量表中点4 | 已有1–7分测量；纳入阈值待固定 |
| 主题归属 | 负面版主要涉及预设主题；中性版可无主题 | 已有0–2个标签；不能直接当作单选主归属比例 |
| 可理解性、自然性 | 两版均容易读懂、像现实行为记录 | 已有1–7分测量 |
| 直接专业关联性 | 两版均不直接提供目标岗位的专业能力证据 | 已有结合岗位描述的1–7分测量 |
| 严重程度、情绪唤醒、可信度 | 识别材料间额外差异，避免把主题差异与这些属性混淆 | 建议补充，尚未实现独立指标 |

这里规定检查方向，未擅自设定正式数值门槛。原 MFV 的人类单选归类阈值不能直接套到当前模型多标签任务。模型重复调用可描述输出稳定性，不能替代独立的人类效度证据。当前 C－B 表示负面私人事件相对中性私人事件的整体影响，仍可能包括负性和严重程度差异。
