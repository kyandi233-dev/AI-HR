# 运行前检查

## 仅做原则实验

- [ ] 确定模型、温度、thinking、max_tokens；全部条件一致。
- [ ] 核对两类定义、两道题和四种顺序；本任务不需要职业资料。
- [ ] 确定run-id、stage和repeat；每条件25次对应100个独立请求。
- [ ] 运行离线测试和批次预览，确认没有携带历史。
- [ ] 确定预算、失败/重试规则和停止规则，再用--execute执行。

## 做职业材料、检验或正式招聘

- [ ] 从O*NET保存来源、访问时间和职业编码；人工核对profile。
- [ ] 审核公司/岗位设定，冻结批准JD与简历。
- [ ] 批准道德配对故事，确定材料检验和筛选标准。
- [ ] 批次选定职业和材料；生成/筛选数据与正式评价分开。
- [ ] A/B/C同一配对只替换背景行为正文，模型不可看到内部条件标签。
- [ ] 全新对话；同批参数、模板、评分锚点和材料固定。
- [ ] 统计保留职业、简历、故事、重复及批次标识。
