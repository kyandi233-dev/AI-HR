# 输入输出字段

## 结果目录

- **实验1：** experiments/exp_1_principles/results/<run-id>/。
- **实验2故事属性：** experiments/exp_2_material_evaluation/results/morality/<run-id>/。
- **实验2岗位关联：** experiments/exp_2_material_evaluation/results/relevance/<职业ID>/<run-id>/。
- **实验3 A/B/C：** experiments/exp_3_hiring/results/abc/<职业ID>/<run-id>/。
- **实验3单独A：** experiments/exp_3_hiring/results/a_only/<职业ID>/<run-id>/。
- **材料准备：** material_preparation/results/<任务>/<职业ID（如适用）>/<run-id>/。
- **批次根目录：** batch.json、results.csv。
- **逐次记录：** records/，每次尝试的 input.json 和 output.json。
- **历史迁移批次：** 保留扁平布局，读取和导出兼容。

## 批次与尝试

- **batch.json：** 阶段、模型参数、材料版本、试次清单和计划顺序。
- **protocol：** 批次开始时的源码摘要，供版本追溯。
- **input.json：** 完整请求、试次编号、尝试编号、计划编号、开始时间与并发设置。
- **output.json：** 原始响应、逐字回答、解析结果、完成时间、模型用量、错误和质量提示。
- **results.csv：** 每次调用尝试一行，两道原则题在同一行。
- **attempt：** a01为首次尝试，后续重试依次使用a02等编号。
- **sequence：** 批次计划编号，用于排序和对应试次。
- **timestamp_utc：** 本次尝试开始时间。
- **completed_utc：** 本次尝试结束时间。
- **concurrency：** 本次运行设置的最大同时请求数。
- **stage：** development、pilot或main；历史导入缺少阶段时为unknown。

## 状态与质量

- **status=ok：** 回答通过当前字段及数值检查。
- **status=error：** 调用、解析、校验或保存草稿时出现错误。
- **status=interrupted：** 请求已登记，最终结果待完成。
- **error_message：** 错误原因。
- **validation_warnings：** 任务键顺序等质量提示。
- **finish_reason：** 模型结束原因，length表示达到输出上限。
- **空白理由：** 计为error，原始响应保留。
- **顺序差异：** 保留模型返回顺序并写入validation_warnings。

## 主要数据列

- **身份：** run_id、task、task_id、attempt、sequence、occupation、condition、repeat、resume_id、pair_id。
- **模型：** requested_model、returned_model、temperature、thinking、max_tokens。
- **用量：** prompt_tokens、completion_tokens、total_tokens。
- **材料：** materials_version、materials_sha256。
- **原则题：** task1/task2各有priority、weight_ability、weight_morality、importance_ability、importance_morality、reason。
- **招聘题：** education_fit、work_experience、professional_skills、accomplishments、overall_suitability、interview_probability、reason。
- **材料评价：** 按任务展开moral_valence、moral_foundations、comprehensibility、naturalness、direct_professional_relevance等字段。
- **实际参数：** 每行保存对应请求的参数；历史行保留原值。

## 导出与历史

- **任务总表：** 各阶段results根目录的<任务名>_all_results.csv。
- **导出：** python -m shared.cli export --task <任务>，按现有JSON重新生成CSV。
- **旧格式转换：** python -m shared.cli migrate-results。
- **原记录：** 转换后的批次legacy/目录。
- **分析：** 选择相应stage、status和attempt，并保留材料配对关系。
