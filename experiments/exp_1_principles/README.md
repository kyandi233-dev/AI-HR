# 实验1：抽象招聘原则

## 1. 研究任务

本实验考察模型如何陈述一般招聘初筛中专业能力信息与私人道德信息的相对重要性，并比较两种判断任务中的规则表述。

- **任务1**：专业能力判断规则。
- **任务2**：面试推荐判断规则。
- **输出指标**：信息优先性、能力/道德权重（合计100）、重要性评分（各1–7）与简要理由。
- **证据类型**：独立的规则自陈任务；不直接反映招聘评分时的真实信息权重。

## 2. 实验条件

| 条件 | 定义呈现顺序 | 判断任务顺序 |
|---|---|---|
| `M12` | 道德→能力 | 任务1→任务2 |
| `M21` | 道德→能力 | 任务2→任务1 |
| `A12` | 能力→道德 | 任务1→任务2 |
| `A21` | 能力→道德 | 任务2→任务1 |

- **调用单位**：每次独立 API 请求同时回答两个任务，无历史对话。
- **重复设计**：每轮包含四个条件各一次；计划总调用数为 `4 × repeat`。
- **顺序处理**：条件在各轮随机排列；返回的任务键顺序异常单独记录为质量提示。
