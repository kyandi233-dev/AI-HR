# 实验1：抽象招聘原则预实验分析报告

> **分析性质**：探索性描述分析（pilot）
> **分析日期**：2026-11-21
> **数据批次**：`20261117_principles_pilot_temp1_01`
> **数据位置**：`results/20261117_principles_pilot_temp1_01/results.csv`
> **研究对象**：DeepSeek API 模型在一般招聘初筛规则制定任务中的自陈判断
>
> 本报告根据仓库内已保存的100条有效调用记录计算。2026-11-16的 `20261116_principles_pilot_02` 是另一次仅4条请求、温度不同的流程测试，**不纳入本次统计**。本报告不使用实验3的招聘评分，也不将原则任务的输出视为模型实际招聘决策中的隐含权重。

## 1. 研究问题

实验1用于考察模型如何明确陈述专业能力信息与岗位外私人道德信息在一般招聘初筛中的使用原则。当前分析关注：

- **任务差异**：专业能力判断（任务1）与面试推荐判断（任务2）的信息权重和重要性是否呈现不同分配模式？
- **定义顺序**：先呈现私人道德信息定义或专业能力信息定义，输出是否不同？
- **任务顺序**：先提出任务1或任务2，输出是否不同？
- **理由内容**：模型是否以专业胜任力、岗位关联性或招聘风险等理由解释其权重分配？

本阶段主要描述方向、数值大小、分布与条件间一致性。尚未将任一对比注册为正式假设检验，也未指定“可以忽略的差异”的等效界值。

## 2. 数据与实验设计

### 2.1 调用设置及纳入规则

| 项目 | 当前批次 |
|---|---|
| `run_id` / `stage` | `20261117_principles_pilot_temp1_01` / `pilot` |
| API及模型 | DeepSeek API；请求和返回模型均为 `deepseek-flash` |
| 模型设置 | `temperature=1.0`；`thinking=disabled`；`max_tokens=2200` |
| 执行方式 | 100条独立请求；批次并发数为100；每条仅包含一条 `user` 消息，无历史对话 |
| 调用规模 | 4种顺序条件 × 每条件25次＝100次 |
| 纳入条件 | `status=ok`，具备两项任务的完整有效结果 |
| 最终纳入 | 100次；失败0次，空白理由0次，非空校验警告0次 |

**分析单位**：一次API调用。每次调用同时产生任务1和任务2的回答，因此两个任务的回答构成同一次调用中的**配对观测**；不同顺序条件由独立请求构成。100次调用均来自同一模型，不能等同于100名人类被试或100个不同模型。

### 2.2 条件与测量

采用2（定义顺序）×2（任务顺序）的顺序操纵：

| 条件 | 定义呈现顺序 | 任务呈现顺序 | 调用数 |
|---|---|---|---:|
| `M12` | 道德→能力 | 任务1→任务2 | 25 |
| `M21` | 道德→能力 | 任务2→任务1 | 25 |
| `A12` | 能力→道德 | 任务1→任务2 | 25 |
| `A21` | 能力→道德 | 任务2→任务1 | 25 |

- **任务1**：判断应聘者能否完成相应岗位的专业工作，应如何使用两类信息。
- **任务2**：决定是否建议候选人进入下一轮面试，应如何使用两类信息。
- **优先类别**：专业能力信息或私人道德信息，二选一。
- **相对权重**：`weight_ability`、`weight_morality`，均为0–100的整数，且同一任务中两者之和为100。
- **重要性**：`importance_ability`、`importance_morality`，各1–7分。
- **理由**：`reason`，由模型生成的简短文本解释。

其中“权重”是提示词要求模型直接填写的**自陈百分比**；它是研究的响应变量，而不是根据招聘评分反推的统计系数。

## 3. 分析方法

### 3.1 数据校验与描述统计

1. 读取该批次 `results.csv`，按 `task_id`、`condition` 和 `repeat` 检查调用记录；仅纳入 `status=ok` 的试次。
2. 检查各任务权重相加是否为100、两个任务的优先类别是否有效、理由是否为空。
3. 分别统计任务1与任务2的优先类别频数、道德权重均值与样本标准差（SD）、中位数、取值范围，以及能力和道德重要性均值。
4. 两类权重互补，因此将**道德权重**作为主要数值指标；能力权重可由 `100－道德权重` 得到，避免重复呈现等价信息。

### 3.2 任务内配对比较

对于第 `i` 次调用，定义：

\[
D_i=W_{i,\text{任务2,道德}}-W_{i,\text{任务1,道德}}
\]

报告 `D` 的均值、SD、范围，以及 `D>0`、`D=0`、`D<0` 的调用数。此差值表示**同一次调用中两个判断任务的自陈权重差**，不应与后续实验3的 `C－B` 招聘评分效应混淆。

### 3.3 顺序条件的描述性比较

- **四条件分组**：分别计算 `M12`、`M21`、`A12`、`A21` 中两项任务的道德权重。
- **定义顺序的边际比较**：合并 `M12/M21` 与 `A12/A21`，计算“道德定义先－能力定义先”的均值差。
- **任务顺序的边际比较**：合并 `M12/A12` 与 `M21/A21`，计算“任务1先－任务2先”的均值差。
- **解释原则**：由于样本按四个条件均衡分配，上述边际均值可以直接比较；当前只报告描述性差异，不将其作为已通过显著性检验的效应。

### 3.4 理由文本的初步阅读

阅读 `task1_reason` 和 `task2_reason`，归纳反复出现的解释方向，明确区分**初步观察的主题**与**已完成系统编码的量化结果**。本次尚未制定正式编码手册，也没有进行独立编码者的一致性检验，因此**不报告理由类别比例**。

## 4. 结果

### 4.1 信息优先性与总体权重

| 指标 | 任务1：专业能力判断 | 任务2：面试推荐判断 |
|---|---:|---:|
| 优先选择专业能力信息 | 100/100（100%） | 100/100（100%） |
| 私人道德信息权重，均值（SD） | 6.25（3.05） | 18.45（4.42） |
| 私人道德信息权重，中位数 | 5 | 20 |
| 私人道德信息权重，最小–最大 | 0–10 | 10–30 |
| 私人道德信息重要性，均值（SD） | 1.68（0.47） | 3.06（0.58） |
| 专业能力信息重要性，均值（SD） | 7.00（0.00） | 6.60（0.49） |

注：权重以百分比表示，均值差以**百分点**表示；重要性采用1–7分量表。SD为样本标准差。

100次调用中，模型在两个任务上**始终优先选择专业能力信息**。但相较于专业能力判断，面试推荐任务允许私人道德信息获得更高的自陈权重（18.45% 对 6.25%），且其道德信息重要性评分也更高。

值得注意的是，任务1的专业能力重要性始终为7分，出现明显的量表上限集中；优先类别在两个任务中也均无变异。因此，当前最能反映不同任务和顺序条件差异的指标是**私人道德信息权重**，而不是优先类别。

### 4.2 同一次调用中的任务差异

| 指标 | 结果 |
|---|---:|
| 任务2－任务1：道德权重均值差 | +12.20个百分点 |
| 配对差值SD | 3.36个百分点 |
| 差值中位数 | +10个百分点 |
| 差值范围 | 0至+20个百分点 |
| 任务2高于任务1 | 99/100 |
| 两任务相等 | 1/100 |
| 任务2低于任务1 | 0/100 |

这说明任务差异在当前批次中方向高度一致：模型在两类任务中均将专业能力置于首位，但在**面试推荐规则**中为私人道德信息分配了更大的辅助权重。

### 4.3 四种顺序条件下的道德权重

| 条件 | n | 任务1：均值（SD） | 任务2：均值（SD） | 任务2－任务1 |
|---|---:|---:|---:|---:|
| M12 | 25 | 7.20（3.25） | 21.60（4.01） | +14.40 |
| M21 | 25 | 5.00（2.50） | 16.60（2.78） | +11.60 |
| A12 | 25 | 7.20（3.56） | 20.00（3.82） | +12.80 |
| A21 | 25 | 5.60（2.20） | 15.60（4.16） | +10.00 |

注：数值为道德信息权重，单位为%；差值单位为百分点。

各条件的共同特征是任务2的道德权重均高于任务1。在四种条件中，`M12` 的任务2平均道德权重最高（21.60%），`A21` 最低（15.60%）；这些都是观察到的条件均值，当前不对其差异作显著性声明。

### 4.4 定义顺序与任务顺序

**定义顺序的边际均值**

| 结果指标 | 道德定义先（n=50） | 能力定义先（n=50） | 差值：道德先－能力先 |
|---|---:|---:|---:|
| 任务1道德权重 | 6.10 | 6.40 | −0.30 |
| 任务2道德权重 | 19.10 | 17.80 | +1.30 |

**任务顺序的边际均值**

| 结果指标 | 任务1先（n=50） | 任务2先（n=50） | 差值：任务1先－任务2先 |
|---|---:|---:|---:|
| 任务1道德权重 | 7.20 | 5.30 | +1.90 |
| 任务2道德权重 | 20.80 | 16.10 | +4.70 |

注：表内均值为百分比，差值为百分点。比较的是模型对**相同任务**在不同呈现顺序下的回答，避免将任务自身差异误认为顺序差异。

本次预实验中，定义顺序的平均差异较小（绝对值0.30–1.30个百分点），而任务顺序的平均差异较大（1.90–4.70个百分点）。特别是在面试推荐任务中，先询问专业能力判断时的道德信息权重平均高出4.70个百分点。

这一模式提示，模型自陈权重可能受到**问题呈现顺序**影响。由于目前仅有单批次预实验数据，尚未完成正式推断或独立复现，不能据此断言定义顺序没有效应，也不能确定任务顺序效应的跨批次稳定性。

### 4.5 输出数值的离散性及理由内容

- **数值取值**：任务1的道德权重只出现0、5、10；任务2只出现10、15、20、25、30。模型将权重集中填写为5的倍数，说明权重具有明显的离散化和表达习惯；均值差应结合这一特点解释。
- **权重约束**：100次调用在两项任务上均满足能力权重与道德权重相加等于100。
- **理由主题（初步观察）**：回答通常将教育、经历、技能与工作成果作为专业能力判断的主要依据；在面试推荐任务中，部分回答还提出私人道德信息可作为识别诚信、合规或其他明显风险的辅助参考，并强调不应取代专业胜任力证据。
- **编码状态**：上述理由归纳来自对保存文本的初步阅读，尚未系统编码。后续若需要量化比较，应制定互斥或可多选的编码规则，标明每项编码的判断标准并进行人工核查。

## 5. 研究解释与限制

**阶段性结果**：本次预实验显示，在一般招聘规则的自陈任务中，模型稳定地将专业能力信息设为优先，但对私人道德信息的使用范围随判断任务改变。相较于专业能力判断，面试推荐允许更高的道德信息辅助权重。任务顺序呈现出大于定义顺序的描述性差异。

这一结果应作如下限制性解释：

1. **自陈原则不等于实际招聘行为**。本实验没有具体岗位、简历或道德故事；是否实际将私人道德信息用于专业能力评分，需要通过实验3的A/B/C评价验证。
2. **当前无法证明顺序效应为零**。观察到的均值差即使较小，也不构成统计等效证据。如希望证明差异小到可忽略，应先定义最小有实际意义的效应范围，再规划等效性检验（例如TOST）。
3. **重复调用的总体有限**。100条请求来自同一模型、同一批次和固定配置，不能据此直接推断其他模型或未来版本。批次并发数为100，尚未评估跨日期、跨批次的稳定性。
4. **输出权重不具备真实行为比例含义**。权重由模型按0–100的格式直接填写，并集中于5的倍数；其解释应限定为显性规则陈述。
5. **探索性比较尚未作推断校正**。本文未报告显著性检验、等效性检验或效应大小标准化检验，也未进行多重比较控制。因此不得将边际均值比较表述为已得到统计确认的因果效应。
6. **理由文本尚未量化编码**。目前仅归纳可辨认的解释方向，不能报告未计算的主题频率，亦不能由理由直接推出模型内部机制。

## 6. 后续分析建议

- **优先完成**：绘制任务1/任务2道德权重的配对分布、四条件箱线图或点图，以及两种顺序因素的边际均值图。
- **理由编码**：围绕“岗位能力证据”“私人信息缺乏直接关联”“诚信/合规/风险”“公平与歧视”“限制私人信息使用”拟定可复核的编码方案，报告各任务中的分布。
- **是否追加调用**：若目的是证明顺序差异可忽略，需先确定等效界值；不得用普通检验的 `p>0.05` 推出“无差异”。目前不建议为这一探索性预实验直接追加大量请求。
- **与实验3衔接**：保留“专业能力判断强调专业证据、面试推荐允许更多道德辅助权重”作为待比较的自陈模式；后续在具体JD、简历和私人背景故事下检验实际评分是否出现相应差异。
- **记录要求**：若进行正式检验或独立重复，应使用新的 `run_id`、保留完整调用参数，并将正式批次与本次pilot结果分开报告。
