## 研究概述

**研究对象**：DeepSeek API 模型在受控招聘任务中的可观察评价行为。

**核心研究问题**：在岗位描述及专业简历保持一致时，岗位外私人道德信息如何影响模型对候选人专业能力与招聘推荐的评价？

研究以中性私人行为为对照，检验负面私人道德信息的增量影响，并考察不同道德主题和职业条件下的差异。另设独立的抽象原则实验，比较模型对信息使用原则的自陈与具体招聘评分。

目前研究限定于虚构候选人和模型输出；专业能力评分属于模型对材料所呈现能力的判断，不代表候选人的真实工作绩效。具体操作化与解释边界见[研究设计](docs/研究设计.md)。

## 研究模块与变量

| 模块 | 任务 | 主要变量与输出 |
|---|---|---|
| 实验1：原则判断 | 不提供具体候选人材料，要求模型陈述一般招聘规则 | 信息优先性、权重（0–100）、重要性（1–7）及理由；操纵定义与问题顺序 |
| 材料准备 | 根据 O*NET 与岗位描述生成匿名简历及配对私人行为故事 | 职业、简历编号、道德基础、故事配对；自然性与专业合理性审核 |
| 实验2：材料评价 | 独立评价背景故事属性与专业关联性 | 道德效价、道德基础归属、可理解性、自然性、直接专业关联性（各适用指标为1–7） |
| 实验3：招聘评价 | 比较 A/B/C 条件，另可单独运行 A | 教育匹配、经历、技能、成果、总体适任性（各1–5）；面试推荐概率（0–100%） |

实验3的条件与主要比较：

| 条件 | 输入材料 | 研究用途 |
|---|---|---|
| A：简历基线 | 岗位描述＋专业简历 | 无私人背景时的评价；单独运行可用于简历预评估 |
| B：中性背景 | 同一岗位描述、简历＋中性私人行为 | 控制添加私人背景信息的影响 |
| C：负面道德背景 | 同一岗位描述、简历＋负面私人道德行为 | 评估相对于中性背景的额外影响 |

- **主要比较**：C－B。
- **辅助比较**：B－A、C－A。
- **材料配对**：B/C 共用简历、岗位描述及故事配对编号；同一简历的 A 结果由多个故事配对共享。
- **能力预评估**：当前 `baseline` 任务可以独立采集 A 评分，但尚未实现自动筛选简历；预实验筛选结果不应直接充当正式实验 A 数据。

## 当前默认模型配置

以下数值汇总自各模块的 `config/settings.json`；实际请求以对应批次的配置及覆盖项为准。

| 用途 | 模型 | temperature | thinking | max_tokens |
|---|---|---:|---|---:|
| JD、简历、故事生成 | deepseek-flash | 1.0 | disabled | 3000 |
| 材料质量审核 | deepseek-flash | 1.0 | disabled | 1600 |
| 实验1：原则判断 | deepseek-flash | 1.0 | disabled | 2200 |
| 实验2：材料评价 | deepseek-flash | 1.0 | disabled | 1600 |
| 实验3：招聘评价 | deepseek-flash | 1.0 | disabled | 2200 |

- **API**：DeepSeek Chat Completions；每次试次独立发送一条 `user` 消息，无历史对话。
- **并发**：`concurrency` 默认 1，可在批次或命令行中调整。
- **批次配置**：实验脚本定义任务，`settings.json` 指定模型配置，批次计划 JSON 指定任务规模、材料版本和运行标识。
- **运行阶段**：`development`（调试）、`pilot`（预实验）、`main`（正式实验）；阶段标签本身不改变模型参数。
- **材料版本**：实验2、3采用独立材料快照；每次运行前核对版本与文件摘要。
- **数据存档**：按批次保留 `batch.json`、`results.csv` 和 `records/`；输入、原始响应与解析结果可追溯。

参数覆盖、执行命令及续跑规则见[运行指南](docs/运行指南.md)，字段定义见[数据与存档](docs/数据与存档.md)。
